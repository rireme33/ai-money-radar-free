# AIに海外AIビジネス情報を集めさせる無料レーダー

公開RSSからAI関連のビジネス・プロダクト情報を取得し、原典URL付きで `data/leads.json` に保存します。GitHub Actionsにより毎日自動収集できます。

## 無料版でできること
- Hacker News / Show HNの公開RSSを定期収集
- AI関連とビジネス関連のキーワードに該当する記事を抽出
- URL単位で重複を取り除く
- 原典リンク付きのJSONを最大300件保持する
- 有料AI APIなしで動作する

**注意：** AIによる意味理解、収益の検証、ランキング、日本向け販売プランの生成は含まれません。自動取得候補の内容は原典で確認してください。「売れる商品」を自動的に保証するものではありません。

## 始め方（GitHubアカウントだけで使う）

1. 右上の **Fork** から自分のアカウントへこのリポジトリを複製する。
2. 複製先リポジトリの **Settings → Actions → General** で Actions とワークフローの書き込み権限（Read and write permissions）を許可する。設定が利用できない場合、組織のポリシーを確認する。
3. **Actions → Collect public AI leads → Run workflow** から1回手動実行する。
4. 実行完了後、`data/leads.json` を開き、`title` と `source_url` を確認する。
5. GitHub Actionsの定期実行は毎日 00:15 UTC（日本時間09:15）に設定。混雑などで遅延したり、実行が停止する場合があります。

※ GitHub Actionsが無効な場合は、リポジトリのActionsページから有効化してください。Fork直後はスケジュールが無効になる場合があります。

## PCから手動実行

Python 3.12以降を利用：

```bash
python scripts/collect.py
python -m unittest discover -s tests -v
```

標準ライブラリのみを使用。利用する公開RSS側のアクセス制限やGitHubの無料枠に注意してください。RSSがすべて失敗した場合は終了コード1を返し、既存の結果を消しません。

## 無料と有料の違い

| 無料スターター | AI金脈レーダー構築キット（4,980円） |
|---|---|
| 公開RSSを収集 | 複数情報源から収集・蓄積 |
| キーワード抽出・URL重複排除 | 分類・ランキング・商品化候補の整理 |
| 原典URL付きJSON | 日本向け商品化レシピ、販売検討のワークシート |
| 売上証拠の検証なし | 有料版も売上の第三者検証は保証しません |

**有料版の案内：** https://note.com/rireme33/n/n64e45df6f23f

無料版は情報収集用、有料版は情報を商品化候補へ整理するためのキットです。収益の保証はありません。

## 安全と再利用

このリポジトリにはAPIキーや秘密情報を含めません。第三者RSSの著作権・利用規約を守ってください。現時点ではライセンス未設定のため、コードの再配布・改変許可を明示的に付与していません。GitHubでのFork操作と一般的な再利用条件は別です。独自ライセンスや採用するOSSライセンスは後日検討します。
